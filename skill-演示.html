🔧 Tool（工具）
本质可被 LLM 调用的函数
谁看到LLM 看到（在 API 的 tools 数组里）
格式JSON Schema（name / description / input_schema）
触发LLM 决定 → 返回 tool_use
副作用真实世界（读文件、跑命令）
例子read_file, edit_file
🧩 Skill（技能）
本质预制的大段 prompt + 可选资源
谁看到Harness 看到，LLM 看到的是注入后的 prompt
格式Markdown + YAML frontmatter
触发用户 /name / 关键字匹配 / harness 自动
副作用只改 prompt，让 LLM "变成" 特定角色
例子/code-review, /simplify, /security-review
